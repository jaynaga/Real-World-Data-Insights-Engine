# Amplify Frontend Template

This directory contains a basic React frontend scaffolded for AWS Amplify integration.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```

## Structure
- `src/` - React source code
- `public/` - Static assets
- `amplify/` - Amplify backend config (run `amplify init` here)

## Amplify Setup
To initialize Amplify, run:
```bash
amplify init
```

Then add features (auth, api, etc) as needed.
